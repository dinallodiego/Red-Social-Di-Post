# 🚀 Di Post - Red Social

Di Post es una aplicación web inspirada en el funcionamiento de una red social moderna, desarrollada como proyecto full stack para poner en práctica el desarrollo de aplicaciones escalables, autenticación de usuarios, gestión de publicaciones e interacción entre usuarios.

El objetivo del proyecto fue construir una plataforma donde los usuarios puedan registrarse, iniciar sesión, crear publicaciones y navegar por el contenido de la comunidad mediante una interfaz moderna e intuitiva.

---


## ✨ Funcionalidades

* 👤 Registro e inicio de sesión de usuarios.
* 🔐 Autenticación segura.
* 📝 Crear publicaciones.
* 📖 Visualización del feed de publicaciones.
* ❤️ Interfaz moderna y responsive.
* ⚡ Comunicación entre Frontend y Backend mediante API REST.
* 📱 Diseño adaptable para dispositivos móviles.

## ⚙️ Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/dinallodiego/Red-Social-Di-Post.git
```

### 2. Entrar al proyecto

```bash
cd Red-Social-Di-Post
```

### 3. Instalar dependencias

Frontend

```bash
npm install
```

Backend

```bash
npm install
```

### 4. Configurar las variables de entorno

Crear un archivo `.env` con las credenciales correspondientes.

Ejemplo:

```env
PORT=3000

SUPABASE_URL=tu_url

SUPABASE_KEY=tu_key

JWT_SECRET=tu_secret
```

### 5. Ejecutar el proyecto

Backend

```bash
npm run dev
```

Frontend

```bash
ng serve
```

La aplicación estará disponible en:

```
http://localhost:4200
```
